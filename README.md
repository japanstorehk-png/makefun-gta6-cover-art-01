Afterglow Press is an offline desktop-browser app that turns a photo and a caption into multi-panel GTA 6-style cover art, then exports a PNG. Photos stay on the machine. No official logos, artwork or fonts.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
